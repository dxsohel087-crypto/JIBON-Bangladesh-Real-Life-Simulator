# JIBON RUNNER

A new Android 3D endless-running game set in realistic Bangladesh.

## Project identity
- Game title: **JIBON RUNNER (জীবন রানার)**
- Genre: 3D endless runner
- Target: Android phones
- Visual direction: realistic / photorealistic 3D; no cartoon look
- World: Bangladesh village roads, rural markets, highways, towns and city streets
- Language: Bangla first, English optional
- Core loop: run, dodge, jump, slide, collect coins, reach distance milestones, take food/rest breaks, continue running.

## Important scope boundary
This is a fresh JIBON RUNNER project. The previous simulator concept and its gameplay are not part of this game. No simulator or tablet mode is planned.

## Current development status
This repository reset establishes the clean JIBON RUNNER project structure and first gameplay scripts. It is **not yet a finished game or APK**. Real 3D character/environment assets, scenes, animation controllers, UI prefabs, licensed sound recordings, device testing and Android build configuration still need to be completed.

## Unity
- Editor: Unity 2022.3.62f1
- Target platform: Android
- Open this repository as a Unity project.
- See [GAME_DESIGN.md](GAME_DESIGN.md) and [DEVELOPMENT_PLAN.md](DEVELOPMENT_PLAN.md).

## First prototype
The first playable milestone is a three-lane runner with jump/slide controls, procedurally spawned road segments, distance tracking and milestone events. Assign the required prefabs and references in a Unity scene before pressing Play.
