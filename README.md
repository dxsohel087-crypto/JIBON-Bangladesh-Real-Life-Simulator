# JIBON RUNNER — জীবন রানার

বাংলাদেশের গ্রাম, বাজার ও রাস্তার অনুপ্রেরণায় Android 3D endless runner.

## এই ধাপে যোগ হয়েছে
- তিন লেনের দৌড়, swipe/keyboard control, jump এবং slide.
- দূরত্ব ও ৫/১০/১৫/২০ কিমি food-break event.
- খাবারের বিরতিতে পুরো গেমের simulation pause.
- কয়েন, বাধা, score এবং best-distance save.
- Unity Editor থেকে starter scene তৈরি করার menu.
- প্রাথমিক runtime world: রাস্তা, সবুজ মাঠ, গ্রামের ঘর, গাছ, player placeholder, obstacles, coins এবং Bangla HUD.

## Starter scene
1. Unity 2022.3.62f1 দিয়ে project খুলুন।
2. Package import শেষ হলে Menu থেকে JIBON RUNNER > Create Starter Scene নির্বাচন করুন।
3. Assets/Scenes/JibonRunner.unity খুলে Play চাপুন।
4. Android build-এর জন্য Build Settings-এ Android platform নির্বাচন করুন।

## সত্যিকারের বর্তমান অবস্থা
এটি প্রথম playable-prototype foundation, final game নয়। Runtime environment এখন primitive placeholder; photorealistic character/vehicle/building models, real animation, Bangla font asset, licensed sound recordings, full menus, performance optimization এবং Android device test এখনো বাকি। APK তৈরি বা পরীক্ষা হয়েছে—এমন দাবি করা হচ্ছে না।
