# JIBON RUNNER — Development Plan

## Milestone 1: playable core
- Create a clean Unity Android project and main scene.
- Add a temporary human placeholder model.
- Implement three-lane movement, jump, slide and collision.
- Spawn/recycle road segments and obstacles.
- Track distance and score.
- Test touch input on a real Android phone.

## Milestone 2: Bangladesh environment
- Build a village road segment kit and a city road segment kit.
- Add Bangla signboards and locally accurate props/vehicles.
- Add a segment director that mixes rural, market, highway and city zones.
- Optimize materials, lighting, LODs and object pooling for Android.

## Milestone 3: audio identity
- Record or license clean Bangladeshi ambience and effects.
- Implement zone-based ambience, spatial vehicle audio and sound mixing.
- Add separate volume settings and test on phone speakers/headphones.

## Milestone 4: progression
- Add coins, missions, records, character cosmetics and save data.
- Add configurable 5 km / 10 km / 15 km / 20 km food-break milestones.
- Build food-break scenes and eating/rest animations.

## Milestone 5: polish and release
- Add menus, pause, game over, revive and settings.
- Test performance on low- and mid-range Android devices.
- Fix crashes, memory growth, audio overlap and control issues.
- Configure Android package name, icon, splash screen and signing.
- Produce and verify an installable APK/AAB.

## Quality gates
Do not mark a milestone complete until it is implemented, compiled and tested. A repository commit or a successful source upload is not proof that an APK works.
